# 图像分类任务专属规则

> 本文件是 [`../SKILL.md`](../SKILL.md) 的**任务专属补充**。
> 通用约束用 **G1–G8** 引用；本文件的图像分类专属规则用 **IC0–IC5** 引用。
> **开始图像分类项目前必须先读本文件。**

---

## IC0 · 前置：数据质量检查（写划分代码之前完成）

图像数据集的坑比表格数据多得多。以下检查**必须在划分之前**跑完，
并输出可复现的统计文件（对应 G5：由脚本生成）。

| 检查项 | 方法 | 必须记录 |
| --- | --- | --- |
| **文件可解码** | 逐张 `PIL.Image.open().verify()` | 损坏文件数量与清单 |
| **色彩模式** | 检查通道数与 `mode` | 单通道 / 三通道 / 混合 |
| **位深与取值范围** | `np.array().dtype` 与 min/max | 是否 uint8、0–255 |
| **尺寸分布** | 统计宽高，含**唯一尺寸组合数** | 是否固定尺寸；若否，必须说明 resize 依据 |
| **重复图像** | **逐字节哈希（MD5）比对** | 重复组数与清单 |
| **亮度/对比度分布** | 每类抽样统计均值与标准差 | 判断归一化策略 |
| **类别分布** | 逐类计数 | **不得照抄官方数字**，必须本地实测 |
| **标签一致性** | 抽样人工核对 | 标注疑点 |

### IC0.1 重复图像必须分类处理

| 重复类型 | 处理 |
| --- | --- |
| **跨类别重复**（同一张图出现在两个类别下） | **两侧全部剔除**。无法判断哪个标签正确，保留任一侧都是注入错误标签 |
| **类内重复** | 保留 1 张 |

> ⚠️ **这是最容易被忽略、后果最严重的一项。**
> 重复样本若跨越训练/测试集，模型等于"背过答案"，测试分数被高估。
> 处理结果必须落盘成清单（含哈希、文件、保留/删除决定）。

### IC0.2 输入尺寸不是"大家都用 224 所以我也用 224"

- 必须**由数据自身的尺寸分布**决定输入尺寸；
- 若数据原生尺寸远小于 224（例如均值 90×80），强上采样会引入插值伪影；
- 应报告**敏感性对照**（如同时跑 64 / 96 / 128），确认结论不依赖于该选择。

### IC0.3 归一化统计量只能来自训练集

- 若使用 z-score 归一化，均值/方差**只能在训练集上计算**，再应用到验证/测试；
- **迁移学习场景慎用源域统计量**：若目标域与源域差异大
  （如 SAR 灰度图 vs ImageNet 自然图像），
  直接套用源域均值方差是**不成立的**；
- 在验证集或全量数据上计算统计量，属于**另一种形式的数据泄漏**（违反 G2）。

## IC1 · 数据集划分：分层抽样，每类比例一致

- 采用**分层抽样（stratified split）**；
- **保证每一类在训练/验证/测试中的比例一致**——
  即各集合内的类别比例应与总体类别比例一致（建议容差 ≤ 1 个百分点）；
- 划分使用**固定随机种子**（对应 G3），结果落盘为索引文件（如 `split_index.csv`）；
- **所有对照模型共用同一份划分**，不允许每个模型各自重新划分；
- 划分后**强制自动断言**：

  1. 三个集合的样本标识（路径）**交集为空**；
  2. 三个集合的**内容哈希交集为空**（防止漏网重复图跨集）；
  3. 各集合类别比例偏差在容差内；
  4. 三集合计 = 去重后总数。

  任一不通过 → **脚本非零退出，不进入训练**。

- 类别不均衡时：以 **Macro F1** 为主指标；
  **不默认做重采样或 SMOTE**（会引入合成样本或丢失真实样本，干扰纯净对比），
  如需类别权重应作为**独立消融**并说明。

## IC2 · 数据增强仅允许在训练集使用

- **数据增强只在训练集启用**；
- **验证集与测试集只做"归一化 + 尺寸调整"**，不得包含任何随机变换；
- 增强必须在**每个 epoch 重新随机采样**（而不是预先固化一份增强后的数据）；

### IC2.1 增强策略必须"物理合理"

图像分类的增强不能只看"常见做法"，要看数据是怎么来的：

| 增强 | 判断依据 |
| --- | --- |
| 旋转 | 若目标的朝向本身任意（如遥感/雷达观测），旋转**物理合理**；否则慎用 |
| 翻转 | 若翻转后的目标在物理上**不存在**，应降级为**消融实验**而非主方案 |
| 亮度/对比度抖动 | 若图像强度有物理含义（如后向散射强度），随意改动会破坏其意义 |
| 颜色抖动 | **灰度图不适用** |

- 每启用一种增强，都要在报告中说明**为什么它对这类数据是合理的**；
- 增强的净效果需通过**消融实验**确认，而不是"加了总比不加好"。

## IC3 · 评价指标

**必须报告的指标集合**（缺一不可）：

| 指标 | 说明 |
| --- | --- |
| **Accuracy** | 整体判对比例 |
| **Macro F1** | **主指标**（各类等权，不受类别规模影响） |
| **每一类的 Precision / Recall / F1** | 定位是哪一类拖后腿 |
| **混淆矩阵** | 同时给出**绝对计数**与**按行归一化**两个版本 |

**补充要求**：

- 混淆矩阵的标签顺序必须**显式记录**（类别名 ↔ 整数索引的映射），
  并在报告中给出对照表——否则读者无法把矩阵与类别对应起来；
- 报告中指标的小数位**统一**；
- 所有指标**必须由脚本自动生成并落盘**（如 `metrics.json`），
  **正文数字必须与产物文件同源**（对应 G5）；
- 指标必须给出**多种子的均值 ± 波动**与逐种子明细（对应 G4）。

## IC4 · 错误样例可视化 + Grad-CAM 可解释性

### IC4.1 错误样例可视化（必须做）

在**测试集**上导出（**全部保留，不得只挑有代表性的**，对应 G6）：

| 类别 | 数量 | 选择依据 |
| --- | --- | --- |
| 正确样例 | 每类若干张 | 置信度最高 |
| **错误样例** | **全部** | 预测 ≠ 真实 |
| 高不确定性样例 | Top-K | 最大 softmax 概率最低 |
| 类别混淆对样例 | 每对若干张 | 混淆矩阵中最大的非对角元素 |

**每张样例图必须标注**：真实标签 / 预测标签 / 置信度 / 文件名（便于回查原图）。

**错误分析必须回答**：

1. 错误是否集中在**特定类别对**？
2. 错误样本的**置信度**是否普遍偏低？（用于评估"置信度阈值拒识"的可行性）
3. 错误样本是否有**共性**（目标过小、被截断、对比度极低、噪声严重）？
4. 高不确定性样本中，正确与错误各占多少？

### IC4.2 Grad-CAM 可解释性观察（必须做）

| 观察对象 | 用途 |
| --- | --- |
| 分类正确且高置信的样例 | 确认模型关注**目标区域** |
| **错误分类的样例** | 看模型"看错在哪" |
| 高不确定性样例 | 看模型犹豫时关注什么 |
| **分对了但热力图落在背景/无关区域**的样例 | 判断模型是否在走**捷径** |

**实现说明**：

- 目标层通常取最后一个卷积/残差阶段的最后一层
  （ResNet 取 `layer4`，自定义 CNN 取最后一个卷积块）；
- 优先使用 `pytorch-grad-cam`；若依赖冲突，可手写 hook 实现（约 50 行，无额外依赖）；
- **Grad-CAM 的结论不能只靠文字描述**，应尽量量化
  （例如统计热力图高响应区域是否落在目标范围内）；
- 若模型疑似依赖背景，应补充**背景消融实验**
  （如裁掉外围背景后重测），交叉验证 Grad-CAM 的结论。

## IC5 · 模型选择依据验证集，不得基于测试集

- **模型选择的唯一依据是验证集结果**；
- **禁止基于测试集指标挑选模型**，包括但不限于：
  - 用测试集选 epoch / checkpoint；
  - 用测试集比较不同超参数；
  - 用测试集挑选"表现最好的那个种子"；
- 流程必须是：

  ```text
  训练 → 按验证集指标选 checkpoint → 冻结 → 在测试集上评估一次 → 报告
  ```

- 测试集**原则上只评估一次**；若因故需要重复评估，必须在报告中
  **明确说明评估了几次、每次的用途**；
- 保存 checkpoint 时必须记录**它是依据哪个验证集指标、在第几轮**被选中的；
- 报告中必须能回答："这个模型是怎么选出来的？"
  如果答案里出现了"测试集"，即违规（对应 G2）。

## 图像分类交付自检清单

在通用清单（SKILL.md）之外，逐条核对：

| # | 对应 | 检查项 | 通过标准 |
| --- | --- | --- | --- |
| 1 | IC0 | 数据质量检查 | 有可复现的统计文件（尺寸/通道/亮度/损坏/重复） |
| 2 | IC0 | 重复处理 | 重复清单落盘；跨类重复已剔除；划分后哈希交集为空 |
| 3 | IC0 | 尺寸依据 | 输入尺寸由尺寸分布推出，并有敏感性对照 |
| 4 | IC0 | 归一化统计量 | 确认只在训练集上计算 |
| 5 | IC1 | 分层抽样 | 各集合类别比例偏差在容差内 |
| 6 | IC1 | 划分唯一 | 所有模型共用同一份划分索引 |
| 7 | IC2 | 增强范围 | 验证/测试集无任何随机变换 |
| 8 | IC2 | 增强合理性 | 每种增强都说明了物理/数据依据 |
| 9 | IC3 | 指标完整 | Accuracy + Macro F1 + 每类 P/R/F1 + 混淆矩阵（含归一化版） |
| 10 | IC3 | 标签映射 | 类别名 ↔ 索引的映射已记录并在报告中给出 |
| 11 | IC4 | 错误样例 | 全部错误样例已导出且标注完整 |
| 12 | IC4 | Grad-CAM | 已覆盖正确/错误/不确定/背景四类观察对象 |
| 13 | IC5 | 模型选择 | 依据验证集；测试集评估次数已说明 |

## 一句话总结

> 图像分类的坑，一半在数据（重复、尺寸、通道、亮度、标签），
> 一半在评估（增强越界、指标不全、拿测试集挑模型）。
> **这两半都要在写第一行训练代码之前就设计好。**
